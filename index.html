Ключові точки маршруту

    Пам'ятка на весь маршрут
    • У місті не швидше 50 км/год, якщо знаки не вимагають менше.
    • Пристебніться, відрегулюйте дзеркала й сидіння до рушання.
    • Покажчик повороту вмикайте заздалегідь і вимикайте одразу після маневру.
    • Перед поворотом займіть відповідне крайнє положення на проїжджій частині.
    • Пропускайте пішоходів на нерегульованих переходах, навіть якщо вони лише ступили на перехід.
    • Не перетинайте суцільну розмітку. Тримайте безпечну дистанцію й бічний інтервал.
    • Біля школи № 4 (вул. Київська) зважайте на знаки «Діти» й переходи, знижуйте швидкість.

    Маршрути побудовано за офіційними схемами ТСЦ МВС № 4842, затвердженими 07.04.2026, і даними OpenStreetMap. Знаки пріоритету взято зі схем і OpenStreetMap, і вони можуть бути неповними. На іспиті керуйтеся реальною дорожньою обстановкою та вказівками екзаменатора.

    Вбудований Street View

    Без ключа кнопка «Street View» відкриває потрібне місце в Google Maps у новій вкладці. Щоб панорама рухалася разом з авто прямо тут, потрібен ваш ключ Google Maps API, а сторінку треба розмістити на власному сайті (наприклад, GitHub Pages). Усередині Claude зовнішні скрипти Google заблоковані.

    Як отримати ключ і поставити ліміт 100 на день
    1. Відкрийте console.cloud.google.com і створіть проєкт.
    2. Billing: прив'яжіть платіжний акаунт. Для безкоштовного обсягу це обов'язково.
    3. APIs & Services → Library: увімкніть Maps JavaScript API.
    4. APIs & Services → Credentials → Create credentials → API key.
    5. У налаштуваннях ключа: Application restrictions → Websites, додайте адресу свого сайту (наприклад, https://ваш-логін.github.io/*). API restrictions → лише Maps JavaScript API.
    6. Google Maps Platform → Quotas (або APIs & Services → Maps JavaScript API → Quotas & System Limits): знайдіть денний ліміт завантажень (Map loads per day) і встановіть 100.
    7. Billing → Budgets & alerts: створіть бюджет, наприклад $1, зі сповіщенням на пошту. Це запасна сигналізація.

    Додаток окремо рахує завантаження панорами в цьому браузері й не створює нових після денного ліміту. Одне заняття зазвичай витрачає одне завантаження: панорама створюється один раз і далі лише переміщується.

    Як розмістити сторінку на GitHub Pages
    1. Зареєструйтеся на github.com і створіть публічний репозиторій, наприклад pdr-routes.
    2. Add file → Upload files: завантажте файл index.html.
    3. Settings → Pages → Branch: main, папка / (root) → Save.
    4. За хвилину-дві сайт відкриється за адресою https://ваш-логін.github.io/pdr-routes/. Цю адресу додайте в обмеження ключа.
    5. Відкрийте сайт, натисніть «Street View» і вставте ключ. Ключ зберігається лише у вашому браузері.
